# Billie Eilish TV

O **Billie Eilish TV** é um site independente feito por fãs para fãs da Billie Eilish. O projeto reúne conteúdos, comunidade, perfis, vídeos, filmes, séries e recursos para Smart TV em uma experiência inspirada em serviços de streaming.

**Site:** https://billieilishtv.site

> Projeto de fãs, sem vínculo oficial com Billie Eilish, sua equipe, gravadoras, produtoras ou plataformas citadas.
