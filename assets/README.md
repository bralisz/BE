# Recursos visuais e arquivos de produção

Esta pasta reúne os arquivos carregados diretamente pelo site publicado.

## Estrutura

- `css/site.css`: aparência completa da interface;
- `js/site.js`: comportamento principal, navegação, conta, catálogo e interações;
- `js/lazy-loading.js`: carregamento otimizado de imagens;
- `icons/`: favicons e ícones usados pelo navegador e pelo PWA;
- `images/avatars/`: avatares predefinidos para os perfis;
- `images/auth/`: imagens das telas de login e autenticação;
- `images/brand/`: logos e identidade visual do Billie Eilish TV;
- `images/pages/`: imagens específicas de páginas, como a tela 404.

Alterações feitas aqui afetam diretamente a experiência visual ou o funcionamento do site em produção.
