# Histórico de atualizações

Cada atualização pública do Billie Eilish TV recebe uma pasta própria com materiais prontos para divulgação e para a página de Releases do GitHub.

## Quando criar uma Release

Uma nova Release é criada somente quando houver:

- alteração visual no site público;
- nova funcionalidade visível aos fãs;
- correção de bug dentro do site público.

Alterações exclusivas do painel administrativo, banco de dados, organização interna ou documentação técnica não criam uma nova Release. O projeto permanece na linha principal `v1.x`.

## Estrutura de cada versão

- `atualizacao.txt`: artigo editorial pronto para publicação;
- `release.txt`: texto pronto para a GitHub Release;
- `lista-de-arquivos.txt`: relação dos arquivos adicionados ou alterados.

A primeira versão pública registrada é a `v1.0.0`.
