# Histórico de atualizações

Cada versão publicada do Billie Eilish TV recebe uma pasta própria com materiais prontos para divulgação e registro técnico.

## Estrutura de cada versão

- `artigo.txt`: texto editorial pronto para publicação;
- `lista-de-arquivos.txt`: relação dos arquivos adicionados, alterados ou removidos;
- `release.md`: resumo formatado para a página de Releases do GitHub, quando necessário.

A primeira versão pública registrada é a `v1.0.0`.
